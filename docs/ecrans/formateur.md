# Écrans de l'espace formateur

Faits produit de l'espace formateur : textes affichés, ordre, conditions d'affichage, composants et fichiers de code. Règles de calcul et données lues : `CLAUDE.md`, section Règles métier, sauf celles encore écrites ici.
Pour l'apparence, lis `docs/design-system/regles-agent.md` jusqu'à la fin : il fait foi. « Fiche X » renvoie à la section X de `docs/design-system/ds-principes-composants.md`.

Fond de ces écrans : `fond-page` du mode formateur (`regles-agent.md`, section 3, « Modes apprenant et formateur »).

## Dashboard formateur

Code : `src/pages/DashboardFormateur.jsx` (+ `DashboardAdmin.jsx`), classes `fd-`. Conteneur `.espace-page.espace-page-etroit`. Trois cas, dans cet ordre : compte `est_admin` → **dashboard admin** ; formateur sans aucun couple élève × cours assigné (aucun cours assigné via `cours_groupes` à un groupe qui a au moins un élève) → **Pour bien démarrer** (non admin, tant qu'aucun cours n'est assigné à un groupe qui compte au moins un élève — `couplesAssignes(...).size === 0` ; dès qu'un couple existe, dashboard normal) : H1 + sous-titre « Bienvenue sur Skillo », **sans les boutons « + Nouveau groupe / + Nouveau cours » de l'en-tête** (doublon avec les étapes) ; une carte blanche (rayon Surface, padding Surface) : titre (Titre de section), « N étape(s) sur 3 », barre fine violette, 3 étapes en blocs `fond-sur-carte` rayon Élément (rond 40 px blanc + numéro ; titre (Titre de ligne), sous-titre (Texte secondaire), bouton à droite) : 1. **Crée ton premier cours** (faite dès un cours ; « Créer un cours ») ; 2. **Crée un groupe et ajoute tes élèves** (faite dès qu'un groupe a au moins un élève ; « Une promo, une classe, une équipe. Tes élèves s'ajoutent par leur email. » ; « Créer un groupe » sans groupe, sinon « Ajouter des élèves » → Détail du groupe le plus récent) ; 3. **Assigne un cours à ton groupe** (« Tes élèves le verront dans « De ton formateur ». » ; « Assigner un cours » → Détail du groupe avec élèves le plus récent ; désactivé tant que 1 et 2 ne sont pas faites ; une fois faite, l'écran laisse place au dashboard). Étape faite : rond `fond-succes` + coche `texte-succes`, titre en encre, sous-titre et bouton masqués. Bouton plein sur la première étape non faite, contour sur les autres. Note (Texte secondaire) sous la liste inchangée.

*En-tête* : H1 « Bonjour / Bonsoir {prénom} » ; dessous, en secondaire (Texte secondaire), « 3 cours · 1 groupe · 12 élèves » (élèves distincts ; « N cours » → Mes cours, « N groupes » → Mes groupes, liens en Texte secondaire fort, règle du lien dans une phrase de `docs/tokens/typographie.md` section 6, même couleur, soulignés au survol seulement). À droite (centrés sur le bloc titre) : « + Nouveau groupe » (contour, ouvre `ModaleNouveauGroupe` puis le Détail du groupe créé — même modale que Mes groupes) et « + Nouveau cours » (violet plein), 48 px. Mobile : boutons côte à côte pleine largeur, 48 px.

*Taux de complétion* (carte globale et carte de chaque groupe ; définition et seuils de la pastille : `CLAUDE.md`, section Règles métier, « Taux de complétion »). Pour un formateur à un seul groupe, les deux chiffres sont égaux. Sous le sous-titre de la carte globale, pastille d'état : « À surveiller » (fiche Pastille, `texte-erreur` sur `fond-erreur`, icône alerte) ; « Bon rythme » (fiche Pastille de statut, seul usage du vert sur vert pâle avec les bonnes réponses ; icône coche)

*Desktop* : grille 2 colonnes égales, écart Entre deux blocs (`grid-template-areas`, 2e rangée en `1fr`) ; **les deux colonnes ont toujours la même hauteur** : « Élèves à relancer » s'étire sur toute la colonne de gauche, et si elle est plus haute, « Tes groupes » s'étire pour rattraper ; le contenu reste en haut de chaque carte (« Voir les N autres » collé sous la dernière ligne). Mobile : hauteurs naturelles : gauche **Taux de complétion** (titre « Taux de complétion », sous-titre « Sur l'ensemble de tes groupes ») puis **Tes groupes** ; droite **Élèves à relancer**. Puis **Activité récente** pleine largeur. Mobile : complétion, relances, groupes, activité.

*Tes groupes* : titre (Titre de section) + « Tout voir » (Mes groupes) ; les 3 groupes les plus récents (`groupes.created_at` si la colonne existe — lue via `select('*')` — sinon ordre alphabétique) en blocs `fond-sur-carte` rayon Élément cliquables (Détail du groupe) : nom (Titre de ligne), « N élèves · N cours », dernière activité (Méta) (« Actif aujourd'hui / hier / il y a N jours », « Pas encore d'activité » = `progression.updated_at` le plus récent des élèves du groupe sur ses cours), chevron ; barre fine piste blanche (fiche Barre de progression) + % (`statsGroupe`, `src/lib/groupes.js`, partagé avec Mes groupes). Pas de pastille « à relancer » ici. Plus de 3 groupes : « Les 3 groupes les plus récents. Le reste est dans Groupes. ».

*Élèves à relancer* (qui et dans quel ordre : `CLAUDE.md`, section Règles métier, « Élèves à relancer ») : lignes `fond-sur-carte` rayon Élément, date en `texte-erreur`, bouton d'envoi → `relancerParEmail` ; 3 lignes puis « Voir les N autres » (déplie) ; sur desktop, la carte étant étirée, le lien est centré verticalement dans l'espace libre entre la dernière ligne et le bas de la carte (au moins un écart Entre deux groupes au-dessus), centré horizontalement ; mobile : juste sous la dernière ligne. Vide : encadré `fond-succes` (rond blanc 44 px + coche `texte-succes`, « Personne à relancer », « Tous tes élèves ont commencé les cours assignés. »).

*Activité récente* : fil sur une colonne, du plus récent au plus ancien (`progression` `en_cours` / `termine`, `updated_at`, **uniquement les cours assignés à l'un des groupes de l'élève** via `cours_groupes` : un élève qui avance sur un cours public non assigné n'y apparaît pas ; les lignes `non_commence` — checklist faite depuis Mode terrain sans ouvrir la leçon — n'y figurent pas) ; une ligne par élève et par cours (garde-fou de dédoublonnage). En-tête : titre (Titre de section), pastilles « Tout / Commencés / Terminés » (fiche Onglet et filtre), recherche 220 px avec loupe « Un élève » (prénom + nom) ; rangée : `docs/tokens/mise-en-page.md`, section 7. Intertitres par jour (Surtitre, secondaire : « Aujourd'hui », « Hier », puis la date courte en français sans année, « 11 sept. », « 3 oct. » ; avec l'année seulement si elle diffère de l'année en cours, « 28 déc. 2025 » — `Intl.DateTimeFormat('fr-FR', { day: 'numeric', month: 'short' })`). « Actif il y a N jours » (groupes) et « Il y a N jours » (relances) gardent la durée. Ligne (lien vers le Détail du groupe de l'élève auquel le cours est assigné ; pastille = ce groupe) : initiales sur rond lavande 40 px, « **Prénom Nom** a terminé / a commencé **Cours** » (Corps courant, noms en gras en Corps courant fort), pastille du groupe (fiche Pastille ; pastille de groupe : voisin de la fiche Pastille de statut), statut (coche + « Quiz 90 % » = meilleur score, ou « Terminé », en `texte-succes` ; icône de progression + « En cours » en `texte-accent`), chevron ; séparateur `bordure-separateur`. « Voir plus » affiche 10 événements de plus. Fil, relances, taux et « Tes groupes » sont calculés côté client à partir d'une seule lecture `progression` (élèves du formateur × cours assignés, avec `cours(titre)`), filtrée ensuite par couple élève × cours assigné (`couplesAssignes`, `src/lib/groupes.js`). Vide : « Pas encore d'activité. ». Mobile : pastilles à la ligne si elles ne tiennent pas, recherche pleine largeur, groupe et statut sous le texte, pas de chevron. Pas de « a repris » : un cours terminé ne repasse jamais en `en_cours` et `progression` ne garde pas d'historique (une ligne par élève et par cours).

**Dashboard admin (`est_admin`, `src/pages/DashboardAdmin.jsx`)** : aucun groupe, aucun nom d'élève. En-tête : H1, pastille lavande « Compte officiel » + « N cours publics », un seul bouton « + Nouveau cours » (pleine largeur sur mobile). Trois cartes blanches (rayon Surface, padding Surface, empilées sur mobile) : libellé (Méta), chiffre (Chiffre mis en avant standard), précision (Méta) `texte-secondaire` sous le chiffre (« 30 derniers jours » sous Apprenants actifs et Cours terminés, « Depuis le lancement » sous Score moyen) — Apprenants actifs (utilisateurs distincts avec une ligne `progression` hors `non_commence` mise à jour sur un cours public dans les 30 jours), Cours terminés (lignes passées à `termine` dans les 30 jours), Score moyen au quiz (moyenne du meilleur score par élève et par cours, cours publics). Carte « Cours les plus suivis » (lien « Tous les cours ») : tableau des 5 cours publics les plus commencés (lignes `progression` hors `non_commence`) (Cours + thème court, Commencés, Terminés, Score moyen) ; mobile : liste « 42 commencés · 18 terminés · 81 % ». Chiffres lus par la RPC `stats_admin_cours_publics()` (la RLS de `progression` / `scores` ne laisse pas l'admin lire ces lignes) — SQL dans `supabase/migrations/0008_stats_admin_cours_publics.sql` (à jouer dans Supabase) ; tant qu'elle n'est pas jouée : « — » et « Statistiques indisponibles pour le moment. ». Aiguillage : `profiles.est_admin = true` sur le profil connecté (lu via `select('*')`) ; `null` / `false` → dashboard formateur.

## Pages formateur

**Règles communes** : titre de page sur le fond de page, une carte blanche par section (fiche Carte). **Conteneur commun** : toutes les pages avec navigation (Dashboard, Mes cours, Mes groupes, Détail cours, Détail groupe) utilisent `.espace-page.espace-page-etroit` (fiche Conteneur de page, colonne Page) ; pas de largeur propre. **Détail cours et Détail groupe** s'affichent avec la barre du haut / la tab bar (pages de consultation), dans `EspaceFormateur` (prop `children`), onglet parent actif (Cours / Groupes) ; seul Créer / modifier un cours reste sans navigation (1200 px max, exception écrite, `docs/tokens/mise-en-page.md`, section 8). Retour « Mes cours » / « Mes groupes » : `RetourFormateur`, fiche Bouton, variante Retour. Actions destructrices : fiches Menu d'actions (`MenuActions`) et Modale de confirmation (`ModaleConfirmation`). Modales : fiche Modale (`Modale`). Pastilles de statut = celles de l'apprenant ; pastille de groupe lavande, « Non assigné » neutre. Composants dans `src/components/formateur/`.

**Mes cours** : « X cours · Y assignés », « + Créer un cours » violet plein (Bouton rond « + » sur mobile), filtres recherche (avec loupe) / thème / groupe (champs blancs), grille 2 colonnes : titre (Titre de carte), « Thème · Leçon · Quiz · Checklist », pastilles des groupes ou « Non assigné ».

**Mes groupes** : « X groupes · Y élèves », « + Créer un groupe » violet plein ; grille : 1 colonne sur mobile, colonnes automatiques sur desktop avec une largeur minimale de carte (`docs/tokens/mise-en-page.md`, section 4) ; carte : nom (Titre de carte), « N élèves · N cours », « Cours terminés » + % et barre fine (terminés ÷ élèves × cours), une pastille d'état par priorité (aucun cours → « Assigne un premier cours » ; élèves à relancer, même règle que le dashboard limitée aux cours du groupe → erreur ; ≥ 70 % → « Bon rythme »). Modale « Nouveau groupe » → ouvre directement le Détail du groupe créé.

**Détail groupe** : H1 + « N élèves · N cours assignés », ajout par email à droite (RPC `find_apprenant_id_by_email`) ; rangée « Cours assignés » (cartes avec barre « X terminés sur N » + carte pointillée « + Assigner un cours » → modale à cases qui ajoute / retire les lignes `cours_groupes` et notifie Make n°2 pour chaque cours ajouté) ; une seule carte « Élèves » (liste et suivi fusionnés) : tableau desktop (élève + email, statut par cours, XP / Badges triables, menu « … » : « Relancer par email », « Retirer du groupe »), cartes sur mobile, 8 élèves puis « Voir les N autres » (lien violet sans soulignement) ; mobile : rangée « Cours assignés » défilante, débord : `docs/tokens/espacements.md`, section 6 ; « Supprimer ce groupe » en bas (menu « … » sur mobile). **Relancer par email** : `relancerParEmail` (`src/lib/relance.js`), `mailto:` en attendant Make n°3, aussi utilisé par l'icône d'envoi des « Élèves à relancer » du dashboard.

**Détail cours** : titre (Titre de contenu), pastille du thème, contenu, groupes ; « Voir comme un élève » (vraie fiche apprenant en **mode aperçu** : `FicheCours apercu`, aucune écriture dans `progression`, `scores`, `user_badges` ni le stockage local, bandeau encre « Aperçu élève · rien n'est enregistré » + « Quitter l'aperçu »), « Modifier », menu « … » (Supprimer). Carte « Avancement des élèves » (barre empilée terminés / en cours / non commencés, score moyen = moyenne des meilleurs scores, « Pas commencé (7 j) » via `cours_groupes.created_at` ; petites cartes : libellé (Méta) secondaire au-dessus, chiffre (Chiffre mis en avant standard) dessous, libellé sur une ligne en desktop ; chiffre en `texte-erreur` seulement s'il est > 0, sinon encre). Contenu de l'en-tête via `partiesContenuCours` (même fonction que la carte de Mes cours, avec les questions et étapes chargées) puis « · » avant les pastilles de groupe. En-têtes repliables : sur mobile, la ligne d'info passe sous le titre, chevron à droite centré verticalement ; desktop : à droite du titre ou carte « Assigne ce cours à un groupe… ». Sections repliables : Leçon (premier paragraphe, 4 miniatures max, « À retenir »), QCM (énoncé + bonnes réponses), Checklist (mode, étapes, bloquantes).
